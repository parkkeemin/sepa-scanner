# 데일리 매매 기준 시스템 v1.0

김종봉·김정수 인터뷰의 매매 기준을 **매일 자동으로 계산되는 종목 리스트 + 매수·익절·손절가**로 만든 애드온입니다.
기존 `sepa-scanner` 레포에 그대로 얹어 GitHub Actions·GitHub Pages·KRX 키·텔레그램 봇을 재사용합니다.

> 이 시스템이 내놓는 모든 가격은 **정해진 규칙에 따른 기계적 계산값**입니다. 예측도, 투자 권유도 아닙니다.

---

## 1. 무엇이 매일 나오는가

| 항목 | 내용 |
|---|---|
| 시장 국면 | 코스피·코스닥 각각 정상 / 혼조 / 주의 / 위험 + 그날의 행동 지침 |
| 트랙 A | 김종봉식 주도주 시작점 — 거래대금 2,000억 이상 장대양봉 |
| 트랙 B | 김정수식 바닥권 턴어라운드 — 52주 하위권 + 대량거래 전환 |
| 종목별 가격 | 돌파 매수 / 눌림 매수 / 손절 / 1차 익절 / 2차 익절 / 추적손절 |
| 수량 | 계좌 금액과 1회 리스크(%)를 넣으면 자동 계산 |
| 1개 조건 미달 | 조건 하나가 모자란 종목 + 무엇이 모자랐는지 (다음날 관찰 대상) |
| 고점 위험 경고 | 보유·관심 종목의 긴 윗꼬리 · 도지 · 갭상승 후 음봉 |

기준이 엄격해서 선별 0종목인 날이 흔합니다. 그래서 **'1개 조건 미달'** 목록을 함께 냅니다.
0종목이 필터 고장인지 시장이 조용한 건지 매일 눈으로 확인하기 위한 장치입니다.

## 2. 파일 구성

```
sepa-scanner/
├── daily_setup.py                     # 스캐너 엔진 (신규)
├── build_sector_map.py                # 섹터 매핑표 생성 (선택, 분기 1회)
├── watchlist.txt                      # 보유·관심 종목 코드 (선택)
├── docs/daily.html                    # 대시보드 (신규)
├── docs/data/daily.json               # 매일 자동 생성되는 결과
├── data/ohlcv/YYYYMM.csv.gz           # 시세 캐시 (자동 생성·자동 정리)
└── .github/workflows/daily-setup.yml  # 평일 18:20 자동 실행
```

기존 `scanner.py`, `monitor.py`, `index.html`, `scan.yml`, `monitor.yml`은 **건드리지 않습니다.**

## 3. 설치 (한 번만)

### STEP 1 — 파일 업로드
받은 4개 파일을 레포에 그대로 올립니다. 경로가 중요합니다.

- `daily_setup.py` → 레포 최상단
- `build_sector_map.py` → 레포 최상단
- `watchlist.txt` → 레포 최상단
- `docs/daily.html` → `docs/` 폴더 안
- `.github/workflows/daily-setup.yml` → 워크플로우 폴더 안

> **주의**: 웹 UI의 "Create new file"로 워크플로우를 만들면 빈 파일이 커밋되는 사고가 두 번 있었습니다.
> 커밋 직전 화면에 내용이 실제로 보이는지 반드시 확인하십시오.

### STEP 2 — 최초 데이터 채우기 (약 15~25분, 1회만)
Actions 탭 → **Daily Setup Scan** → Run workflow → `backfill` 값을 **260**으로 입력 → 실행.

260거래일(약 1년)치 전종목 시세를 캐시에 채웁니다. 이후 자동 실행은 하루치만 받아 1분 내로 끝납니다.

### STEP 3 — 대시보드 확인
`https://parkkeemin.github.io/sepa-scanner/daily.html`

`daily.json`이 아직 없으면 샘플 화면이 뜹니다. STEP 2를 마치면 실제 결과로 바뀝니다.

### STEP 4 (선택) — 섹터 매핑
트랙 A의 '같은 섹터 동반 급등' 확인을 자동화하려면 로컬에서 한 번 실행 후 결과 파일을 커밋합니다.

```bash
pip install finance-datareader
python build_sector_map.py      # -> data/sector_map.csv
```

없어도 동작합니다. 그 경우 대시보드에 "섹터 매핑 없음 — 수동 확인"으로 표시됩니다.

### STEP 5 (선택) — 보유 종목 등록
`watchlist.txt`에 6자리 코드를 한 줄씩 넣으면, 매일 그 종목들의 고점 위험 캔들을 함께 점검합니다.

## 4. 판정 기준 (전부 숫자로 고정)

### 시장 국면 — 지수가 먼저다
자체 산출 지수(시장 전체 시가총액 합)로 판정합니다.

| 상태 | 조건 | 행동 |
|---|---|---|
| 정상 | 20일선 > 60일선, 지수 > 20일선 | 기준 충족 시 정상 진입 |
| 혼조 | 위 조건 일부만 충족 | 기준 충족 종목만 소량 |
| 주의 | 지수 < 20일선 | 신규 1종목까지 · 비중 절반 |
| 위험 | 지수 < 60일선 | **신규 진입 중단** |
| (과열구간) | 1년 범위 상위 10% | 분할 진입 · 기계적 익절 |

### 트랙 A — 주도주 시작점 (6개 전부 충족)
1. 거래대금 **2,000억 이상**
2. 등락률 **+5% ~ +15%** (상한가·과열 제외)
3. 장대양봉 실체: 시가 대비 +3% 이상 & 실체가 전체 범위의 50% 이상
4. 윗꼬리가 전체 범위의 35% 이하
5. 거래대금이 20일 평균의 **3배 이상**
6. 250일 저점 대비 **3배 미만** (이미 수배 오른 자리 제외)

### 트랙 B — 바닥권 턴어라운드 (7개 전부 충족)
1. 52주 범위 **하위 40% 이내**
2. 직전 60일 박스권 폭 40% 이하 (장기 횡보)
3. 전일 대비 거래량 **300% 이상**
4. 60일 평균 거래량의 **4배 이상**
5. 등락률 +5% ~ +25% 양봉
6. 윗꼬리 35% 이하
7. 거래대금 100억 이상

### 공통 제외
우선주 · 스팩 · 리츠 · ETN / 1,000원 미만 / 시총 500억 미만 / 상장 60거래일 미만 /
**기준봉 고저 폭 20% 초과**(변동성 과대) / 손익비 1.0 미만

### 가격 계산
| 항목 | 계산식 |
|---|---|
| 돌파 매수 | 기준봉 고가 × 1.001 (호가단위 올림) |
| 눌림 매수 | 시가 + (종가−시가) × 0.5 |
| 손절 | 기준봉 저가 × 0.99, 단 매수가 −10%보다 깊어지지 않음 |
| 1차 익절 | 매수가 +10% (물량 50%) |
| 2차 익절 | 매수가 +20% (물량 30%) |
| 잔여 20% | 고점 대비 −7% 추적손절 |

호가단위는 2023-01-25 개정 기준(유가증권·코스닥 공통)으로 반올림합니다. 확인일 2026-08-30.

## 5. 기준값 바꾸기

`daily_setup.py` 상단 상수를 고치거나, 워크플로우에 환경변수를 넣으면 됩니다.

```yaml
env:
  A_MIN_VALUE: "100000000000"   # 코스닥까지 넓히려면 1,000억으로
  MIN_RR: "1.5"                 # 손익비 기준을 높이려면
  A_CHG_MAX: "10"               # 영상 원칙대로 +10%까지만
```

## 6. 3개월 검증 루틴 (영상의 마지막 조언)

1. 계좌 금액을 **100만 원**으로 두고 대시보드의 권장 수량대로만 매매
2. 매수 직전 HTS/MTS **자동감시주문**에 손절·1차·2차 익절을 반드시 먼저 등록
3. 매일 기록: 종목 / 트랙 / 기준가 / 실제 체결가 / 결과 / 원칙 위반 여부
4. 3개월 뒤 **승률보다 손익비와 원칙 준수율**을 먼저 확인
5. 원칙 준수율 90% 이상이 나온 뒤에만 금액을 올림

## 7. 알아둘 한계

- KRX 일별 데이터 기준이므로 **장중 실시간 신호가 아닙니다.** 장 마감 후 다음날 계획을 세우는 용도입니다.
  장중 실행 신호는 기존 KIS 감시엔진(`monitor.py`)이 담당합니다.
- 거래정지·관리종목·시장경보(투자주의/경고/위험) 지정 여부는 KRX 일별매매 데이터에 없습니다. **주문 전 HTS에서 직접 확인**하십시오.
- 무상증자·액면분할 등 수정주가 반영은 KRX 원본값을 따릅니다. 급격한 왜곡이 보이면 해당 종목은 건너뛰십시오.
- 백테스트가 아닌 **당일 조건 판정기**입니다. 이 기준이 과거에 얼마나 통했는지는 별도 검증이 필요합니다.
